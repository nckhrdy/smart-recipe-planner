# Smart Recipe Planner

Snap a photo of the ingredients you have on hand and get **5 structured recipes** you can cook tonight. Refresh for a genuinely new set, and save the ones you like.

A mobile app built with **Expo** (React Native). Not a chat interface — the recipe list and recipes are highly structured.

> **Status:** In design. Start with the product brief: [`docs/product/2026-06-18-smart-recipe-planner.md`](docs/product/2026-06-18-smart-recipe-planner.md).

## Project structure
- `docs/` — product brief, and (later) architecture decision records
- `prototypes/` — HTML screen prototypes (design-first, before any Expo code)
- _(later)_ `client/` — the Expo app · `server/` — a thin API proxy that holds the AI key
